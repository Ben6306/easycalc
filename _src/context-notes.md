# 홈 화면 unslop 작업 노트 (2026-11-13)

## 진단 (unslop 스킬 기준, 가벼운 수준 → 다듬기 모드)
- 계산기 카드 9개가 똑같은 모양이고, 초록 '계산하기' 버튼도 9개라 강조가 사라짐
- h1이 metaTitle 키워드 나열이고, 계산기 9개 중 4개가 빠져 있음
- 제목 굵기가 700, 간격 18·14·11px처럼 4px 단위에서 벗어남
- 홈에 눈에 띄는 요소가 없음. 제품의 상징인 영수증 카드는 계산기 안에만 있음
- PWA 버튼이 초록 테두리 알약 모양

## 방향 (사용자 승인)
- 제품: 설치·가입 없이 한국에서 실제로 받는 돈·내는 돈을 계산하는 생활 계산기
- 성격: 정확하고, 담백하고, 영수증처럼 믿음직함
- 세계관: 급여 명세서와 은행 영수증 (점선, mono 숫자, 원 단위)
- 모먼트: 첫 화면에 실제 계산 결과 영수증 1장 (연봉 5천만·1인·식대 20만 → 월 3,571,587원)
- 시그니처: 영수증 점선과 아래쪽 톱니 모양 (기존 `.receipt` 재사용)

## 결정
- metaTitle·metaDesc(검색 결과 제목)는 그대로 두고 화면 h1만 새 문구 `homeH`로 바꿈 (사용자 선택)
- 영수증 숫자는 직접 쓰지 않고 calc.html `netPay`로 계산한 값을 build.py `HOME_SAMPLE`에 넣음. test_calc.py가 매 빌드마다 netPay와 비교해서, 요율이 바뀌었는데 홈 숫자를 안 고치면 빌드가 멈춤
- 영수증 라벨은 계산기와 같은 번역 키(payslip, rateTag, netEst, grossM, pension …)를 그대로 써서 새 번역을 줄임
- '이 조건으로 직접 계산하기' 버튼은 공유 링크 형식 `/salary/#pay=…`로 계산기에 같은 값을 채워서 엶
- 새 CSS는 `.home` 아래로 한정함. `.card`, `main.page` 간격 등은 계산기·가이드 페이지와 같이 쓰므로 건드리지 않음
- 계산기 페이지의 4px 단위 위반(`.wrap gap:18`, `.card padding:18` 등)과 영수증 머리글 대문자 자간(.rhead)은 이번 범위 밖. 보고서에 제안으로만 남김
- EXTRA_CSS의 `.card{gap:8px}`가 계산기 페이지 `.card{gap:14px}`를 덮어쓰는 것으로 보임. 기존 동작이라 손대지 않고 보고만 함
